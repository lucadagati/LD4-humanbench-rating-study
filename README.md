# CPS-HumanBench rating study

Static web version of the human rating study of the CPS-HumanBench project (University of
Messina). Participants rate 40 simulated smart-home days; no personal data are collected and the
answers are sent by e-mail or downloaded by the participant. The pages contain no information about
which controller produced each day.

Generated by `scripts/prepare_rating_study.py --site` in the main project repository.
Configuration (pilot banner, contact, optional submission endpoint, ethics reference): `config.js`.
